# Бот вакансий в Telegram: инструкция по запуску

Бот каждые 10 минут заходит на карьерные сайты компаний и присылает вам в Telegram новые вакансии со ссылкой, как только они появились.

**Что ищет:** Лондон; Marketing, PR / Public Relations / Press, Events, Communications; уровень Intern / Internship или Executive; без слов unpaid и commission based.

**За какими компаниями следит сейчас:**
- LVMH (Dior, Louis Vuitton, Celine, Moët Hennessy, Guerlain и другие)
- Richemont (Cartier, Van Cleef & Arpels, Piaget, Chloé и другие)
- Estée Lauder Companies (MAC, Jo Malone, La Mer, Clinique и другие)
- Ralph Lauren
- CHANEL
- Маркетинговые и PR-агентства: Hanover, Burson, DEPT, HWL, Fully Vested, Influencer, Uncovered, TEAM LEWIS, Freuds
- Рестораны и кофейни: Soho House, Dishoom, Black Sheep Coffee, Hawksmoor

Районы и почтовые индексы Лондона (Shoreditch, Southwark, SE1, W1 и другие) бот тоже считает Лондоном.

Чтобы добавить компанию, пришлите Claude ссылку на её страницу с вакансиями.

**Как работает первый запуск:** при первой проверке каждой компании бот только запоминает вакансии, которые уже открыты, и ничего не присылает. Дальше приходят только новые.

Настройка делается один раз, примерно за 20 минут. Шаги 1–2 можно сделать с телефона, шаги 3–6 удобнее делать с компьютера.

---

## Шаг 1. Создайте бота в Telegram

1. Откройте в Telegram **@BotFather** и нажмите Start.
2. Отправьте `/newbot`.
3. Введите имя бота, например `Daryna Jobs`.
4. Введите username, который заканчивается на `bot`, например `daryna_jobs_bot`.
5. BotFather пришлёт **токен** вида `1234567890:AAH...`. Сохраните его в заметках. Никому его не отправляйте, в том числе в чат с Claude.
6. Откройте своего нового бота по ссылке от BotFather и нажмите **Start**. Без этого бот не сможет вам писать.

## Шаг 2. Узнайте свой chat ID

1. Откройте в Telegram **@userinfobot** и нажмите Start.
2. Он пришлёт ваш **Id**, это число, например `512345678`. Сохраните его.

## Шаг 3. Создайте аккаунт и репозиторий на GitHub

1. Зарегистрируйтесь на **github.com** (бесплатно).
2. Нажмите **+** справа вверху → **New repository**.
3. Название: `job-bot`. Выберите **Public**.
   - Почему Public: проверка каждые 10 минут бесплатна только для публичных репозиториев. Токен при этом скрыт (шаг 5), видны только код и список ID уже просмотренных вакансий.
4. Нажмите **Create repository**.

## Шаг 4. Загрузите файлы бота

1. В новом репозитории нажмите **uploading an existing file**.
2. Распакуйте архив `job-bot.zip` на компьютере и перетащите в окно браузера **все файлы и папку `.github`** из папки `job-bot`.
   - Папка `.github` на Mac скрыта. Нажмите в Finder `Cmd + Shift + .`, чтобы её увидеть.
   - Если папка не загружается, создайте файл вручную: **Add file → Create new file**, имя `.github/workflows/jobs.yml`, вставьте содержимое файла `jobs.yml` из архива.
3. Нажмите **Commit changes**.

В репозитории должны быть: `bot.py`, `requirements.txt`, `seen.json`, `README.md` и `.github/workflows/jobs.yml`.

## Шаг 5. Добавьте секреты

В репозитории: **Settings → Secrets and variables → Actions → New repository secret**. Добавьте 2 секрета (название точно как здесь):

| Name | Что вставить |
|---|---|
| `TELEGRAM_TOKEN` | токен от BotFather (шаг 1) |
| `TELEGRAM_CHAT_ID` | ваш Id из @userinfobot (шаг 2) |

## Шаг 6. Запустите и проверьте

1. Откройте вкладку **Actions**. Если GitHub спросит, нажмите **I understand my workflows, go ahead and enable them**.
2. Слева выберите **Job alerts** → **Run workflow** → mode: **test** → **Run workflow**.
3. Через 1–2 минуты в Telegram придёт отчёт: сколько вакансий бот видит на сайте каждой компании.
   - ✅ компания работает.
   - ⚠️ или ❌ перешлите отчёт Claude, он поправит настройку этой компании.
4. Запустите ещё раз с mode: **run**. Придёт сообщение «👀 Бот начал следить за компаниями».
5. Готово: дальше бот сам проверяет сайты каждые 10 минут.

## Полезно знать

- **Скорость.** Обычно вакансия приходит через 10–30 минут после публикации. GitHub иногда запускает проверки с опозданием, в часы нагрузки до часа.
- **Ошибки.** Если сайт какой-то компании не открывается около часа подряд, бот пришлёт ⚠️ сообщение. Перешлите его Claude.
- **Изменить фильтры** (роли, город, стоп-слова): напишите Claude или отредактируйте списки в начале файла `bot.py`.
- **60 дней без изменений.** GitHub может отключить расписание, если в репозитории долго ничего не меняется. Бот сам сохраняет изменения при новых вакансиях, но если придёт письмо от GitHub об отключении, нажмите в нём **Enable**.

## Свежие вакансии в LinkedIn вручную

Бот не заходит на LinkedIn: это запрещено правилами LinkedIn, и аккаунт могут заблокировать. Но свежие вакансии там можно смотреть самой:

1. Найдите вакансии в LinkedIn, например `PR Intern`, локация `London`.
2. В фильтре **Date posted** выберите **Past 24 hours**.
3. В адресной строке найдите `f_TPR=r86400` и замените на `f_TPR=r1800`. Это вакансии за последние 30 минут.
4. Сохраните ссылку в закладки и открывайте пару раз в день.
